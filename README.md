# 🚀 Matrix-70-App | A&N Visual Global

Üdv a jövőben! A **Matrix-70-App** az A&N Visual és a Cs-Aion Labor közös fejlesztése, egy professzionális karrier-motor, amely tűpontos logikával és esztétikával segít a globális siker elérésében.

## ✨ Miért a Matrix-70?
- **3-Nyelvű Mátrix**: Teljes körű HU, EN és DE támogatás a kezelőfelületen és a tartalomban is.
- **Matrix Summary Selector**: 15 előre kalibrált szakmai bemutatkozás, amely azonnal alkalmazkodik a választott nyelvhez.
- **Global Matrix Layouts**: 15 választható vizuális stílus, a minimalistától a prémium hospitality megjelenésig.
- **PWA Technológia**: Telepíthető Web Appként, manifest támogatással a natív élményért.

## 🛠️ Technikai Stack
- **Engine**: Pure JavaScript (Zéró-Tippelés elvű logika).
- **Data**: Dinamikus `database.js` moduláris szerkezet.
- **Style**: Dinamikus CSS változók (`--main-color`) a teljes testreszabhatóságért.

## 📱 Telepítési útmutató
1. Nyisd meg a GitHub Pages által generált URL-t.
2. Androidon válaszd a "Hozzáadás a kezdőképernyőhöz", iOS-en a "Hozzáadás a főképernyőhöz" opciót.
3. Használd appként a Matrix-70-et!
